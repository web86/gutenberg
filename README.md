# Gutenberg с нуля — Web86 Blocks

**30 дней — 30 уроков — собственная библиотека блоков WordPress.**

Практический курс на русском языке: каждый день изучаем одну тему Gutenberg, пишем код и постепенно собираем переиспользуемые блоки для клиентских сайтов.

## Как устроен репозиторий

- `NN-short-goal/README.md` — понятный разбор темы, шаги и полный код.
- `NN-short-goal/<example>/` — исходники практического примера.
- Каждый урок можно пройти отдельно. Позже объединим полученные блоки в **Web86 Blocks**.

## Требования

- Локальная установка WordPress с редактором блоков.
- Node.js и npm для сборки примеров.
- Редактор кода (например, VS Code).

Учебные плагины сначала проверяйте локально, прежде чем устанавливать на рабочий сайт.

## Программа

**1–7:** первый блок, структура, поля, настройки, стили, карточка услуги.  
**8–14:** медиа, SVG, ссылки, вложенные блоки, Hero, FAQ, единый плагин.  
**15–21:** PHP-рендеринг, WP_Query, собственные типы записей, каталоги, фильтры.  
**22–28:** REST API, AJAX, Interactivity API, формы, theme.json, безопасность.  
**29–30:** тестирование, релиз, публикация библиотеки и портфолио.
